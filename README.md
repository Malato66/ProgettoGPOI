# ProgettoGPOI
Progetto gpoi 


- Realizzazione dell'ambiente virtuale: python -m venv .venv
- Attivazione dell'ambiente virtuale: .venv\Scripts\activate
- installazione librerie per la gestione backEnd: pip3 install django
- Creazione del ramo LoginPage dell'applicazione: python manage.py createapp loginPage
- Inizializzazione del database: python manage.py migrate
- Creazione dell'utente 'admin': python manage.py createsuperuser admin
- Configurazione dei file di sistema: urls.py, settings.py
- Creazione dei template personalizzati: templates/login.html


- Per ricreare il virtualenviroment:
  - python -m venv .venv
  - pip install -r requirements.txt.
