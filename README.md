# ProgettoGPOI
Progetto gpoi 


- Realizzazione dell'ambiente virtuale: python -m venv .venv
- Attivazione dell'ambiente virtuale: .venv\Scripts\activate
- installazione librerie per la gestione backEnd: pip3 install django


- Per ricreare il virtualenviroment:
  - python -m venv .venv
  - pip install -r requirements.txt.
